INSTALAÇÃO
1. Desligue completamente o servidor.
2. Mantenha o arquivo plugins/SimpleCustomTab-1.1.1.jar.
3. Substitua somente plugins/SimpleCustomTab/config.yml pelo config.yml deste pacote.
4. Ligue o servidor normalmente.

RECARREGAMENTO
- Para alterações pequenas futuras, use /sctreload.
- Para esta troca completa, prefira reiniciar o servidor.
